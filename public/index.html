v0.0.1 — Dynamic API Documentation Server

SERVE YOUR API DOCS LIVE.

Drop a Postman collection, get a blazing-fast HTML documentation site — served dynamically with Node.js. No static exports. No stale docs.

Clone & Deploy How it works
config.js 
module.exports = {
  port: 3000,
  collections: [
    {
      name: "my_api.json",   // Postman export filename
      pathName: "/api/docs",  // URL path to serve at
      type: "postman"          // generator type
    }
  ]
}

// How it works
DEAD SIMPLE.
01
CLONE THE REPO

Get the server running locally in seconds. No framework magic, just Express.js.

git clone https://github.com/denizyts/api_doc_server
02
DROP YOUR POSTMAN EXPORT

Export your Postman collection as JSON (v2.1) and place it in collection_exports/.

03
CONFIGURE YOUR ROUTES

Map collection filenames to URL paths in config.js. Multiple collections, multiple paths — all handled.

04
START & SHIP

Run the server. Your beautiful API documentation is live and always up to date.

node app.js
